# Support

Start with the [product documentation](https://azure.github.io/AI-Landing-Zones/agent-landing-zone/)
and [troubleshooting guide](https://azure.github.io/AI-Landing-Zones/agent-landing-zone/troubleshooting/).

For UI bugs or feature requests, search the
[UI issues](https://github.com/Azure/agent-app-ui/issues) before opening a new
issue. For platform deployment or cross-component problems, use the
[Agent Landing Zone issues](https://github.com/Azure/agent-landing-zone/issues).
Include the component version, deployment topology, steps to reproduce, and
sanitized error details. Do not include tokens, credentials, personal data,
or private environment names.

Report suspected vulnerabilities through [the security policy](SECURITY.md),
not public issues. For community conduct concerns, see
[the code of conduct](CODE_OF_CONDUCT.md).
