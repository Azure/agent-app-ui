# Contributing

Create your working branch from `develop` and open contribution pull requests
against `develop`, not `main`. Only same-repository `release/X.Y.Z` branches
may open release pull requests against `main`.

Keep changes focused. Include a short description of the change, relevant
tests and their results, and documentation updates when needed. See
[AGENTS.md](AGENTS.md) for repository engineering rules.

Pull requests run the quality gate automatically, and it must pass before
merge. Automated checks support manual review; they do not replace it.

## Code of conduct and CLA

This project follows the [Microsoft Open Source Code of Conduct](CODE_OF_CONDUCT.md).
Most contributions require a Contributor License Agreement (CLA) confirming
that you have the right to contribute the code. The CLA bot will explain any
required steps on your pull request; see https://cla.opensource.microsoft.com.
